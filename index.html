체험학습 사진으로 학부모 안내 페이지 만들기

정리 안 된 체험학습 사진 폴더와 계획서를 맡기면, 연속 사진마다 대표 한 장만 남기고 학생이 고르게 나오도록 골라 휴대폰에서 보는 안내 페이지 한 장을 만들어 줍니다.

준비물

  • 실습 사진(아래에서 내려받기). 체험학습 하루치 60장과 운영계획 PDF가 들어 있습니다.
  • Claude 데스크톱 앱 Code 탭과 유료 계정

따라 하기

  1. 실습 사진을 내려받아 압축을 풀어 주세요.

    '실습2_Cowork용_체험학습폴더'에 사진 60장과 체험학습_운영계획.pdf가 있습니다. '실습1_채팅용_사진15장'은 같은 사진 중 15장만 담은 가벼운 연습용입니다. 내 사진으로 하실 때는 원본 말고 복사본 폴더를 따로 만들어 주세요.

    실습 사진 받기압축 파일 · 18MB · 사진 75장 + 계획서

  2. Code 탭에서 '실습2_Cowork용_체험학습폴더'를 골라 주세요.

  3. 먼저 연속 사진에서 대표 사진만 골라 달라고 해 보세요.

    부탁 문장 · 대표 사진 고르기
    체험학습을 다녀와서 사진을 많이 찍었어. 이 폴더의 사진을 분석해서 연속사진마다 대표사진을 하나씩 골라줘.

    실습에서는 Claude가 사진 이름의 촬영 시각으로 60장을 20장면(연속 17묶음 + 단독 3장)으로 나누고, 묶음마다 사진을 나란히 놓고 비교했습니다. 흐린 컷, 어두운 컷, 너무 확대돼 잘린 컷은 빼고, 웃는 얼굴이 크고 또렷한 컷을 남겼습니다. 사진마다 선명도와 밝기를 숫자로도 재서 판단을 확인했습니다.

  4. 이제 안내 페이지를 부탁해 주세요. 조건에 번호를 붙여 적습니다.

    부탁 문장 · 실습에서 쓴 문장

2. 계획서에서 학교·체험명·날짜·장소만 읽어 줘. 시간표는 페이지에 넣지 마.

    실습에서 Claude가 함께 알려 준 것

    계획서에서는 학교·체험명·날짜·장소 4가지만 씁니다. 그래서 기본 양식에 있던 '오늘의 미션'과 '안전 관리' 칸은 빼겠습니다.

    사진 설명은 활동만 적습니다. 예: "커다란 나무를 꼭 안아 보며 나무의 숨결을 느껴요"

    그 학생 사진을 1장 더 넣거나, 미션·안전 칸을 다시 넣을 수도 있습니다. 바꿀 부분이 있으면 말씀해 주세요.

교과서 PDF와 진도표 엑셀을 주면, 교과서에 인쇄된 쪽번호를 기준으로 차시마다 PDF 한 개씩 나눠 줍니다. 나눈 차시 PDF로 제미나이 노트북에서 인포그래픽도 만들어 봅니다.

    • 01차시_단원 도입.pdf
    • 02차시_구석기 시대 사람들의 생활 모습을 알아볼까요.pdf
    • 03차시_신석기 시대 사람들의 생활 모습을 알아볼까요.pdf
    • 04-05차시_청동기 시대 사람들의 생활 모습을 알아볼까요.pdf
    • 06차시_고조선 사람들의 생활 모습을 알아볼까요 주제 마무리.pdf
    • 07-08차시_삼국과 가야의 성립과 발전 과정을 알아볼까요.pdf
    • … (모두 15개)

  1. 제미나이 노트북에 차시 PDF 한 개를 소스로 올리고, 스튜디오의 '인포그래픽'에서 맞춤설정을 열어 주세요.

    실습에서는 03차시 PDF를 올리고 한국어, 가로, 시각적 스타일 자동, 세부정보 '간결하게'로 두었습니다.

-글은 짧게 한국어로

  2. 결과를 교과서와 대조해 주세요.

    실습에서는 인포그래픽의 용어와 문장 19개를 Claude Code에게 03차시 교과서 본문과 하나씩 맞춰 보게 했습니다. 조·기장 밭농사, 갈판·갈돌, 빗살무늬 토기, 움집, 가락바퀴·뼈바늘이 모두 교과서에 있는 내용이었습니다.

실제로 있었던 일 · 결과를 직접 확인한다

처음 만든 노트북의 제목이 "신석기 시대와 청동기 시대 사람들의 생활 모습"으로 붙었습니다. 그런데 03차시에는 청동기 내용이 없습니다.

원인은 펼침면이었습니다. 교과서 17쪽과 18쪽이 한 장에 붙어 있어 화면에 보이는 반쪽만 잘랐는데, 가려진 반쪽의 글자가 파일 안에 그대로 남아 AI가 그 글까지 읽은 것입니다. 이 페이지의 예시 파일은 가려진 반쪽을 실제로 지워 고친 것입니다.

펼침면이 있는 교과서라면 나눈 뒤에 아래처럼 한 번 더 부탁해 주세요.

막힐 때

차시 파일이 한 쪽씩 밀려 있어요

표지·차례가 있는 교과서는 PDF 쪽과 인쇄된 쪽이 다릅니다. "PDF 몇 쪽이 교과서 몇 쪽이야"처럼 한 군데를 알려 주고 다시 맞춰 달라고 해 주세요.

파일 하나가 너무 커요

그림이 많은 쪽은 수십 MB가 되기도 합니다(실습의 01차시는 23MB). "메신저로 보낼 수 있게 10MB 이하로 줄여 줘"라고 부탁해 주세요.

스캔한 교과서라 글자를 못 읽는대요

쪽번호를 글자로 읽을 수 없으면 Claude가 쪽을 그림으로 열어 직접 확인합니다. 시간이 더 걸리니 첫 차시가 시작하는 PDF 쪽 번호를 알려 주면 빨라집니다.

3교시 · Claude Code + 한글 스킬

1학기 계획서로 2학기 운영계획·활동지 만들기

1학기 운영계획(한글 hwpx) 한 장을 주면, 같은 양식에 2학기 내용을 채운 운영계획 초안과 학생 활동지를 만들어 줍니다. 샘플 활동지를 보여 주면 그 디자인으로 PDF 활동지도 만듭니다.

준비물

  • 실습 자료(아래에서 내려받기): 1학기 운영계획(hwpx), 샘플 활동지(PDF), 한글 스킬 2개
  • 결과를 열어 볼 한글(HWP) 프로그램. 한글이 설치돼 있으면 Claude가 PDF로 바꿔 쪽 모양까지 확인합니다.
  • 내 계획서로 하실 때는 .hwpx 파일이어야 합니다. .hwp는 한글에서 '다른 이름으로 저장 → HWPX'로 바꿔 주세요.

한글 스킬 설치하기

Claude가 한글 파일(hwpx)의 양식을 그대로 살려 고치도록 돕는 스킬 2개를 설치합니다. 처음 한 번만 하면 됩니다.

hwpx 스킬한글 문서 읽기·만들기 · 63KB hwpx-form-filler 스킬서식에 내용 채우기 · 5KB

  1. 방법 1 · 앱에서 올리기 (클릭만으로)

    데스크톱 앱 설정의 Capabilities에서 '코드 실행 및 파일 생성(Code execution and file creation)'을 켜 주세요. 그다음 왼쪽 메뉴 Customize → Skills → + → Upload a skill에서 zip 파일을 고르고, 목록에서 스킬을 켜 주세요. 두 파일 모두 같은 방법으로 올립니다.

  2. 방법 2 · 폴더에 넣기

    zip 압축을 풀어 나온 hwpx, hwpx-form-filler 폴더를 C:\Users\(내 이름)\.claude\skills\ 안에 넣어 주세요. macOS는 ~/.claude/skills/입니다. 각 폴더 안에 SKILL.md가 바로 보여야 합니다.

  3. 설치됐는지 확인해 주세요.

    Code 탭 입력창에 /skills를 입력하거나, "사용할 수 있는 스킬 알려 줘"라고 물어보면 hwpx 두 개가 보입니다.

따라 하기

  1. 실습 자료를 내려받아 압축을 풀어 주세요.

    '실습_공문폴더'에 2026학년도 인성교육실천주간 운영계획.hwpx(1학기)와 샘플 활동지 2026.2학기 안전교육주간 활동지.pdf가 있습니다.

    공문 실습 자료 받기압축 파일 · 0.5MB · 계획서 + 샘플 + 스킬

  2. Code 탭에서 '실습_공문폴더'를 고르고, 부탁 문장을 붙여 넣어 주세요.

    부탁 문장 · 2학기 초안
    이 폴더에는 2026학년도 1학기 인성교육실천주간 운영계획이 있어. 이 파일을 바탕으로 2학기 인성교육실천주간 운영계획과 학생 활동지 초안을 만들어 줘.

  3. Claude가 짚어 준 것을 읽어 주세요.

    실습에서 Claude가 짚어 준 것

    표·글꼴·번호 상자는 원본 그대로 두고 내용만 바꿨습니다. 주제는 1학기 '배려와 존중'에 이어 "협력과 책임으로 함께 성장하는 우리"로 정했습니다.

    기간이 정해져 있지 않아 11. 9.(월)~11. 13.(금)으로 임시로 넣었습니다. 학사일정을 알려 주시면 바꾸겠습니다.

    1학기 원본의 "6. 2.(월) ~ 6. 6.(금)"은 요일이 맞지 않습니다. 6월 2일은 화요일이고, 6월 6일은 토요일(현충일)입니다.

    끝자리가 빠진 정신건강 위기상담 번호 "1577"은 1577-0199로 채웠습니다. 다른 기관 번호 두 곳은 확인이 필요합니다.

    Claude는 한글로 결과를 열어 PDF로 바꿔 보고, 원본과 같은 2쪽인지, 표의 글자가 단어 중간에서 끊기지 않는지까지 확인한 뒤 고쳤습니다.
