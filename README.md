# Claude 교사 업무 자동화 1일차 · 따라 하기

Claude Code(Claude 데스크톱 앱의 Code 탭)로 교사 업무 세 가지(체험학습 사진으로 학부모 안내 페이지, 교과서 PDF 차시별 분할, 1학기 계획서로 2학기 운영계획·활동지)를 따라 하는 안내 페이지입니다.

- 페이지: https://shway81-droid.github.io/teacher-day1/
- `files/`: 실습 자료(체험학습 사진 75장과 계획서, 교과서와 진도표, 공문 계획서와 샘플 활동지, 한글 스킬 2개)
- `examples/`: 완성 예시(안내.html, 차시별 PDF 3개, 2학기 운영계획·활동지)

요금과 기능은 2026년 10월 기준입니다.
